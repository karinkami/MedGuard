# MedGuard AI - Интеллектуальная система диагностики заболеваний

## О проекте

MedGuard AI - это комплексная система для ранней диагностики сердечно-сосудистых заболеваний и диабета с использованием передовых методов машинного обучения. Проект реализует ансамбль из 6 современных ML-алгоритмов для максимально точной оценки рисков.

## Основные возможности

### ❤️ Диагностика сердечных заболеваний
- **Ансамбль из 6 моделей:** Random Forest, Gradient Boosting, Extra Trees, XGBoost, LightGBM, CatBoost
- **Точность:** >73%
- **Анализ факторов риска:** давление, холестерин, глюкоза, ИМТ, возраст, вредные привычки
- **Персонализированные рекомендации** по уровню риска

### 🍭 Диагностика диабета
- **Ансамбль из 6 моделей:** те же алгоритмы, оптимизированные под диабет
- **Точность:** >97%
- **Анализ:** HbA1c, уровень глюкозы, ИМТ, возраст, сопутствующие заболевания
- **Интеллектуальные рекомендации** по профилактике

### Особенности
- **Оценка уверенности прогноза** через анализ согласия моделей
- **Визуализация** результатов с помощью Plotly
- **Медицинская интерпретация** факторов риска
- **Интерфейс** на Streamlit
